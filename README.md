# HideShot

Сервис для скрытия личных данных на скриншотах перед отправкой.

Автоматически находит чувствительные данные, позволяет скрывать заданные слова и закрашивать области вручную. Изображения обрабатываются локально в браузере и не отправляются на сервер.

> Проект находится в разработке. Ниже описаны возможности первой версии.

## Возможности

- Загрузка до 10 изображений через выбор файлов или перетаскивание.
- Вставка скриншота из буфера обмена.
- Распознавание текста на русском и английском.
- Автоматический поиск email, телефонов и типовых токенов.
- Поиск слов и фраз, введённых пользователем.
- Ручное выделение областей для закрашивания.
- Проверка и корректировка найденных областей.
- Отмена и повтор действий для каждого изображения.
- Скачивание отдельного PNG или всех результатов ZIP-архивом.
- Интерфейс на русском и английском.

## Как работает

1. Загрузите изображения или вставьте скриншот.
2. Дождитесь распознавания текста.
3. Проверьте автоматически выделенные данные.
4. При необходимости введите дополнительные слова и фразы — каждую с новой строки.
5. Добавьте или удалите области закрашивания вручную.
6. Скачайте результат.

Изображения распознаются по очереди. Дополнительные слова применяются ко всем загруженным файлам.

## Технологии

| Технология | Назначение |
|---|---|
| React + TypeScript | Интерфейс и логика приложения |
| Vite | Разработка и сборка |
| Zustand | Состояние редактора |
| Tesseract.js | Распознавание текста и его координат |
| Canvas API | Закрашивание и экспорт изображений |
| CSS Modules | Стили |
| i18next + react-i18next | Переводы интерфейса |

Поиск чувствительных данных выполняется правилами на TypeScript. Облачные ИИ и платные API не используются.

## Приватность

- Изображения и распознанный текст обрабатываются на устройстве пользователя.
- Бэкенд и регистрация не требуются.
- При первом запуске может потребоваться загрузка движка OCR и языковых моделей.
- При экспорте выбранные области закрашиваются непосредственно в итоговом изображении.

## Ограничения

Распознавание может ошибаться, особенно на изображениях с мелким, размытым или нестандартным текстом. Автоматический поиск не гарантирует обнаружение всех чувствительных данных.

Перед отправкой обязательно проверьте результат. Пропущенные данные можно скрыть вручную.

Скорость обработки зависит от устройства, размера изображений и выбранных языков распознавания.
